## 2. Colors ↔ frequencies for binaural?

### What tradition actually does
- Chant **mantras/varṇas** (voice) with breath, placement, attention  
- **Not** “root = 396 Hz” as a classical teaching  
- *Nāda*, *spanda*, speech levels — metaphysics + practice, not Hz tables  

### What modern sources say
| Claim | Reality |
|-------|---------|
| Fixed Hz per chakra | **No universal chart** — many conflicting systems (256 / 396 / 194…); tuning reference changes everything (A=440 vs 432) |
| Mantra approach | Seed syllables (LAM/VAM/RAM…) **without fixed Hz** — closest to traditional use |
| Research that *does* show effects | Mantra/focused sound → stress, HRV, mood — often via **breath, rhythm, attention**, not one magic number |
| Cymatics | Sound **does** create geometry on plates/water — frequency + boundary matter — **lab physics**, not proof each chakra is a Hz |

### Honest product policy (Stonedoorway + Sanskrit Worlds)
```text
Voice phonemes  = tradition’s uccāra (the real practice)
Binaural bed    = aesthetic state support (alpha/theta as mix settings)
Per-phoneme Hz  = OPTIONAL personal mnemonic — never “Abhinavagupta’s science”
Color           = scaffold + source-tagged when attested
```

**If you want a frequency layer anyway:**
- Use **bed** frequencies as *your* experiment (e.g. soft 6–10 Hz beat for calm study)  
- Pair with **spoken** mātṛkā + color  
- Log what *you* feel — personal phenomenology, not doctrine
