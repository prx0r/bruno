## Architecture

| # | Layer | What it is |
|---|-------|------------|
| **1** | **Varṇa** | Atoms: articulation first (tongue, breath, voicing, duration). Then colour / locus / feel / rhythm as **your** phenomenology. |
| **2** | **Pāṇinian compression** | Māheśvara Sūtras + **pratyāhāras** — addressing system over sound-space (`ac` lights up the vowel field). |
| **3** | **Operators** | Sandhi, endings, prefixes, suffixes, reduplication… as **felt actions** (merge, lengthen, redirect, mark agency…), not dictionary defs. |
| **4** | **Dhātu** | Roots as **persistent agents** (√gam = motion process). Operators act on the invariant; manifestations change. |
| **5** | **Verse** | Actual Sanskrit first. Sound contour → decompile → **discovery** drives which grammar you learn next. |
| **6** | **Generative** | AI asks *what will happen?* — predict sandhi, parse, generate forms. |
| **7** | **Direct recognition** | Colours/characters/operators **compress away**. Scaffold dies into fluency. |

**Musical analogy:** phonemes = timbres · pratyāhāras = scales · roots = motifs · morphology = transformations · sandhi = voice-leading · meter = temporal geometry · verse = composition.

## First laboratory verse

(Bṛhadāraṇyaka 1.3.28)

- Discover **√gam** + causative **gamaya**  
- Encounter **-aḥ → -o** sandhi

## Discovery ≠ hallucination

- You **can** discover productive transformations quickly  
- Roots are **not** uniform — test hypotheses against new examples  
- Counterexamples = model reorganization (Levin)  
- Narrow start: **full varṇa by articulation** + **one tiny verse** + **first operators the verse forces**  

**Bottom-up** phoneme → operation → word → sentence  
**Top-down** verse → decompile → discover operations → update world
