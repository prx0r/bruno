## What Abhinavagupta actually recommends (practice grammar)

From **Tantrasāra Āhnika 5** (varṇa-uccāra / “Rite of the Phonemes”) and related Trika material:

| Element | Practice |
|---------|----------|
| **What to chant** | Phonemes from **ka → sa** (and full alphabet A→Kṣa in broader tradition), **with or without vowels** |
| **How** | **Internally (madhyamā) or intensely contemplated** — not only loud recitation |
| **Why it “works” in-text** | Contact with Awareness **without conventional meaning** — sound as awareness-vibration, not “words about things” |
| **Breath** | Moon (inhale) / sun (exhale) with movement + pause; balance (equipose) |
| **Body fuse** | Heart · throat · lips as one; subtle centers along suṣumnā |
| **Colors** | Some authorities: internal colors arise (white, yellow, blue…) — **practice-specific**, not one universal chart |
| **Order** | **Mātṛkā** (conventional A→Kṣa) = emission / body install · **Mālinī** (secret transposition) = later / withdrawal |

## How *we* chant each phoneme (tonight)

Two layers — **never corrupt pronunciation with mnemonics**:

### Layer A — Phonetic (real Sanskrit)

For **each** phoneme:

1. **Articulation** — tongue place, aspiration, voiced/unvoiced, nasal  
2. **Duration** — short 1 mātrā · long ~2 mātrā · anusvāra/visarga ~½  
3. **Resonance** — feel where it lands in mouth/throat/chest  
4. **Aloud → whisper → mental** (vaikharī → madhyamā)

## Mātṛkā row chant script (~10–12 min)

| Step | What |
|------|------|
| 1 | Sit · spine long · soft breath ×5 |
| 2 | Optional 1:4:2 nāḍī (laya-breath protocol) |
| 3 | **Row 1 gutturals** ka kha ga gha ṅa — aloud, feel root |
| 4 | Silence 15–20s |
| 5 | Rows 2–3 (palatals, retroflex) |
| 6 | **Row 4 dentals** ta tha da dha na — **heart, longer pause** |
| 7 | Rows 5–7 (labials, semi-vowels, sibilants) |
| 8 | **Vowels** a ā i ī u ū… — whole field |
| 9 | Drop to **mental** repeat of one row |
| 10 | Silence / laya 60s |
| 11 | One line log |

**Short night:** rows **1 + 4 + 8** only.

## First verse lab — Bṛhadāraṇyaka 1.3.28

```text
असतो मा सद्गमय ।
तमसो मा ज्योतिर्गमय ।
मृत्योर्मा अमृतं गमय ॥

asato mā sad gamaya
tamaso mā jyotir gamaya
mṛtyor mā amṛtaṃ gamaya
```

**Sound first:** a-sa-to | mā | sad-ga-ma-ya — hear dental `dg` transition · repeated **gamaya** motif ×3.

**Then discover:**
- √gam = motion root  
- **gamaya** ≈ causative “cause to go / lead”  
- asato/tamaso — **-aḥ → -o** boundary (sandhi encounter)  
- Architecture: **SOURCE → mā → DESTINATION → √gam + operator** ×3  

**Audio:** Yoga Vidya / mantra podcasts — *Asato mā sad gamaya* (listen for contour, then chant yourself).
