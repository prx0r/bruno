# StoneDoorway — audial imagination OS (no screen)

> Doorways = tunnels · AI voice activates world bed · you **reconstruct** the grid in your head  
> Progressive grid: **1 window → 2×2 → 3×3** · select → walk through → inhabit  
> **All imaginal / auditory** — nothing rendered on a display for the practice itself  
> Companion: `STONEDOORWAY-OS-IMAGINATION.md` · lobby: `worlds/stonedoorway-os-lobby.json`  
> Audio bed map: `worlds/stonedoorway-world-beds.json`

---

## Core insight (yours)

Stone Doorways aren’t “pages” or “apps.”  
They’re **tunnels**.

When you say:

> *“Let’s go into Sanskrit world”*

the AI:
1. confirms the doorway  
2. **activates that world’s binaural bed**  
3. starts the **audial reconstruction drill**

When you enter the OS itself (the Stone Doorway *as system*), you don’t get a free map.  
You must **remember/reconstruct the worlds** — first one, then four, then nine.

**The grid is cognitive, not graphical.**

---

## The stack (audio-only)

```text
YOU
  voice: "Let's go into Sanskrit world"
      ↓
AI ASSISTANT (StoneDoorway OS)
  1. doorway confirm (tunnel cue)
  2. world bed ON (binaural / drone)
  3. voice script = the world
  4. optional familiar whisper
  5. work loop
  6. "Return to the threshold" · bed fades
```

| Layer | What you hear |
|-------|----------------|
| **Threshold** | hum · “You are now entering the Stone Doorway…” |
| **Reconstruction** | “Name what you see in the dark…” / “What is the first world?” |
| **Grid** | “Four windows. Reconstruct them.” / “Nine pillars.” |
| **Doorway** | “Walk through the one you named.” |
| **World bed** | binaural for that world only |
| **Work** | chant · Laya · Pāṇini mini · speak |
| **Return** | “Bring yourself back to the threshold.” · bed down |

## Progressive reconstruction (beginner → OS)

| Stage | Grid | AI job | You |
|-------|------|--------|-----|
| **S1** | **1 window** | Hold one world steady in the dark | Name it · walk through |
| **S2** | **2×2** | Offer four windows; refuse to show all | Reconstruct four · pick one |
| **S3** | **3×3** | Full lobby | Name all nine · select · walk |

**Rule:** you don’t advance because time passed.  
You advance because you **reconstructed** the grid.

---

## Windows, not tiles

Each world = a **window / opening / doorway** in the dark:

- You **see** it only as you name or sense it (imaginal)  
- Selecting = *walking toward* it  
- Crossing = tunnel cue + **world bed on**

This is why doorways > menus:  
**selection is an act of attention**, not a click.

## Voice scripts (audial)

### 1. “Let’s go into Sanskrit world” (direct doorway)

```text
Doorway open.
Sanskrit world bed on.

You are in the tunnel.
When you arrive, the first window is in front of you.
Name the window. Walk through it.
Install one row. Speak one word. Return.
```

### 2. OS boot — reconstruct one world (S1)

```text
You are in the Stone Doorway.
The atrium is dark.
There is only one window.
What is it?
Name it. Walk through.
```

### 3. OS boot — reconstruct four (S2)

```text
Threshold.
Four windows in a 2×2 grid — but you build them in the dark.
Reconstruct: Mātṛkā, Laya, Pāṇini, Threshold.
Choose one. Walk through. Bed on when you cross.
```

### 4. OS boot — nine pillars (S3)

```text
Nine worlds. Reconstruct the lobby.
Name all nine. Then choose one door.
Bed activates as you walk through.
Return when the work is done.
```

## What “grid lobby” means without a screen

| Screen idea | Audial-imaginal version |
|-------------|-------------------------|
| UI grid | You **build** 2×2 / 3×3 in mind |
| Window image | You **name** the opening |
| Click | You **walk toward** |
| Navigate | AI: “left, right, above…” only if you ask |
| App chrome | Threshold hum + familiar presence |

**If you can’t reconstruct it:**  
AI doesn’t cheat with a visual dump.  
AI: *“Stay. Name what’s missing. The grid gets clearer when you remember it.”*

## Familiar in audial mode

- Appears as **voice cue** (“Your familiar is at the threshold”) + colour in mind  
- Can **whisper** the missing world name if you’re stuck (optional training aid — turn off for pure recall)  
- Lives in the tunnel between lobby and worlds
