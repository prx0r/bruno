## What’s useful from Gurdjieff (for us)

### 1. Self-remembering — the golden key
Ouspensky’s model: **divided attention**

```text
one arrow  → object observed
two arrows → object + self ("I am here")
three factors → organism · situation · something higher/third
```

| Maps to | How |
|---------|-----|
| StoneDoorway boot | “Remember yourself.” before lobby |
| Contractio | Hold phoneme + feel self + locus |
| Third factor (lab) | Familiar / faculty / “I am here in the doorway” |
| Notoria intention | Faculty memory/intellect/eloquence is the third anchor |

**Practical:** every session starts with *presence*, not content dump.

---

### 2. Waking sleep — why the OS exists
Ordinary life = semi-hypnotic sleep.  
We only “remember” when we self-remember.

| Maps to | How |
|---------|-----|
| Threshold | Doorway = deliberate wake moment |
| Audial OS | Voice + bed = attention container |
| Reconstruction drill | You can’t reconstruct if asleep |

**Practical:** the boot *is* the wake ritual.

---

### 3. Law of Seven / octaves / intervals / shocks — process grammar
Nothing runs in a straight line.  
Processes slow at **mi–fa** and **si–do**.  
They need **conscious shocks** or they **deviate**.

```text
do → re → mi → [fa interval] → sol → la → si → [do interval]
     ↑                    ↑
   start            mid plateau
                        SHOCK
```

| Maps to | How |
|---------|-----|
| Learning Sanskrit | Week 2–3 **mi–fa** = “why am I doing this?” |
| Memory staged tests | M3/M4 plateaus = natural intervals |
| Conditioning | Same bed cue at real-life interval = shock |
| Notoria faculty | **Eloquence** as mid-process shock (you *speak*) |
| Laya silence | **si–do** — complete the octave, don’t drop |
| World packages | GUIDE can insert “shock” prompts at intervals |

**Practical lab rule:** when motivation dies mid-session, that’s an interval.  
**Shock options:** speak one word · contractio 30s · familiar cue · bed change · log.

---

### 4. Law of Three — three forces in every complete act
Active · Passive · Reconciling.

| Lab triad | Meaning |
|-----------|---------|
| **Active** | Chant / intent / will to enter |
| **Passive** | Bed / receptivity / silence |
| **Reconciling** | Speak · log · familiar · third factor |

Maps cleanly to Notoria session shape:

```text
intention (active) → figure/install (passive hold) → speak/log (reconciling)
```

---

### 5. Self-observation without analysis
Observe machine; don’t moralize.

| Maps to | How |
|---------|-----|
| Session log | “What stuck?” not “am I bad?” |
| Memory tests | Miss = stage data, not shame |
| Castle Abbreviata ethic | Extract what you need |

---

### 6. Three centers
Intellectual · Emotional · Moving.

| Center | Lab |
|--------|-----|
| Intellectual | Pāṇini traces · understanding |
| Emotional | Colour · familiar · contractio |
| Moving | Body · speak · breath · conditioning sports |

Notoria faculties already cover much of this.  
Gurdjieff names the **center** language explicitly.

---

### 7. Mechanicalness / “man cannot do”
Awakening isn’t a single willpower move.  
Needs **structure + repeated shocks**.

| Maps to | How |
|---------|-----|
| Progressive grids | 1→2→4→9 not optional fluff |
| Daily CLI | Automation of shell so will isn’t the bottleneck |
| Conditioning | Rehearsal + real cue until pattern takes over |

---

### 8. Conditioning engine (your sports/confidence case)
Octave view:

```text
IMAGINAL + BED          start octave (do–re–mi)
REAL LIFE interval      mi–fa — bed/cue = shock
SUSTAIN                 sol–la
RETURN / log            si–do second shock
```

Honest label: **state-dependent rehearsal + attention** — not supernatural proof.
