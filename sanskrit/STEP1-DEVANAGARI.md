# Step 1 — Devanagari · phonemes · YouTube chant · binaural

> Realistic start. No cathedral yet.  
> Goal in 7–10 days: **write + recognize the main akṣaras, hear them, chant one row with color/feeling, layer a quiet binaural bed under your own voice.**

---

## What you’re building

```text
WRITE  Devanagari letters
HEAR   phonemes (you + YouTube reference)
CHANT  mātṛkā rows with form + color + emotion
LAYER  binaural bed UNDER your voice (not instead)
RECALL write from memory without the chart
```

## Day 1 — The chart (print / open)

Write (or print) one page:

### Vowels (svara) — start here
```
अ  आ  इ  ई  उ  ऊ
a   ā  i   ī  u   ū

ऋ  ॠ  ऌ  ḹ  ए  ऐ  ओ  औ
ṛ   ṝ  ḷ  ḹ  e  ai  o  au

अं  अः
aṃ  aḥ
```

### Consonants — series (write one series per day)
| Series | Letters | Color scaffold |
|--------|---------|----------------|
| Gutturals | क ख ग घ ङ | red / root |
| Palatals | च छ ज झ ञ | orange / sacral |
| Retroflex | ट ठ ड ढ ण | yellow / solar |
| **Dentals** | **त थ द ध न** | **green / heart** |
| Labials | प फ ब भ म | blue / throat |
| Semivowels | य र ल व | indigo / third eye |
| Sibilants | श ष स ह | violet / crown |

**Handwriting:** pen + paper beats app-only. Trace each letter 3×, then copy freehand once.

## Days 2–3 — Hear + chant one series

### YouTube / audio (find once, reuse)

Search YouTube (or any audio) for:
- `Sanskrit alphabet pronunciation` · `Devanagari akshara audio`
- `Matrika chanting` · `Sanskrit phonemes slow`
- Specific row: `dental consonants Sanskrit ta tha da dha na`

**How to use YouTube (carefully):**
1. Pick **one** slow, clear source (native or classical teacher preferred)
2. Listen once with chart open
3. **Then put it away** — chant **yourself** (that’s the tradition’s uccāra)
4. Optional: keep YouTube as reference only during first pass — not as a karaoke crutch forever

**Better long-term:** record **your own** row chants (phone) — that’s what installs.

## Days 4–5 — Binaural *under* your voice

| Layer | What | Policy |
|-------|------|--------|
| **Under** | Soft binaural bed (Stonedoorway `matrika-night` or similar) | Aesthetic only — not Hz-per-phoneme doctrine |
| **Over** | **Your voice** chanting the row | This is the practice |
| **Then** | Drop bed; mental repetition; silence (Laya) | Bindu on one letter |

### Bed settings (start quiet)
```
mode: binaural
beat: 6–8 Hz (calm) — your experiment, not a claim
tone/intensity: low
darkness/activity: low–medium
duration: 20 min
```

Doorway file: `bruno/sanskrit/worlds/matrika-night.json` · Stonedoorway presets folder.

**Rule:** if the bed overpowers your voice, turn the bed down. Voice wins.

## Days 6–7 — Memorize + recall

| Drill | Time |
|-------|------|
| Write series from memory | 5 min |
| Chant series eyes-closed | 5 min |
| Name color + locus for each letter | 3 min |
| One Sanskrit word using the series (e.g. *ka* → a real word) | 5 min |
| Log one line | 1 min |

**Week 1 exit test:** write all gutturals + dentals from memory; chant both series with color association without looking.

## Session template (25 min)

```text
1. Notoria general          2 min   (memory | understanding)
2. Write / review chart     5 min
3. Chant one series aloud   5 min   (optional bed under voice)
4. Feel: form + color + locus  3 min
5. Recall without chart     5 min
6. Silence (Laya)           3 min
7. Log                      1 min
```
