## What Abhinavagupta actually says (the “science”)

### 1. Phonemes are not just letters
- **50 varṇas = 50 forms of Śiva’s reflective awareness** (*vimarśa*) — Āhnika 3  
- Begin with **A = Anuttara**; unfold through vowels → consonants → KṢ  
- Whole alphabet = **śabdarāśi** (assembly of sound) — source of mantra and language  

### 2. Two cakras of the same power
| | Mātṛkā | Mālinī |
|--|--------|--------|
| Order | Conventional A→KṢ | Secret transposition (NA→PH…) |
| State | Unaroused mothers | Aroused / interpenetrating vowels+consonants |
| Use | Outer nyāsa, body purification | Inner deposition, Parā / Kālasaṁkarṣiṇī |

### 3. Four levels of speech (vertical “science”)
```
PARĀ     undifferentiated speech-consciousness
   ↓
PAŚYANTĪ meaning as integrated whole
   ↓
MADHYAMĀ internal differentiated language
   ↓
VAIKHARĪ audible articulated phonemes
```
Music sits mostly at **madhyamā** (subtle, non-segmented like linguistic units). Sweet sound increases **vīrya** (creative power) — Tantrāloka 3.228–230.

### 4. Twelve-stage sonic ascent (dvādaśānta)
A → U → M → Bindu → Ardhacandra → Nirodhīnī → **Nāda** → Nādānta → Śakti → Vyāpinī → Samanā → Unmanā  
(Netratantra / Svacchanda via Tantrāloka Vol.1 Appendix A)  
**Kuṇḍalinī = Śakti at stage 9** — sound-power rising through suṣumnā.

### 5. Body + color + placement (your instinct is attested)
- **uccāra, karaṇa, dhyāna, varṇa, sthāna-prakalpanā** (Mālinīvijayottara 2.21 via Abhinavagupta)  
  = utterance/breath · bodily instrument · visualization · phonemes · **construction of loci**  
- **Varṇa + color meditation** — Tantrāloka 5.148–150: blue and other colors in the heart  
- **AHAṀ** — A (anuttara) + H (visarga/emission) + Ṁ (bindu) — phonemic architecture of “I”  
- **Nyāsa** — letters placed on body (practice-specific; not one universal chart)

## Binaural night track — how to do it honestly

### What Abhinavagupta supports
- Practice with **sound + breath + placement + visualization**  
- Levels of speech as a **descent/ascent** model  
- Colors in contemplation  
- Mantra/phoneme as **concentrated consciousness**, not only “meaningful sentence”  

### What is **modern overlay** (label it)
| Overlay | Status |
|---------|--------|
| **Binaural beats** (Hz L/R) | Modern audio tech — **not** in Tantrāloka |
| **One Hz per phoneme** | **Not attested** — inventing this as “Abhinavagupta science” is overclaiming |
| **Cakra colors** | Attested in practice texts; schemes differ |
| **Dream incubation of phonemes** | Modern synthesis (you already flagged this) |

### Recommended night protocol (Stonedoorway-compatible)

```text
1. Safety: quiet headphones, low volume, stop always available
2. Bed: soft binaural / drone — aesthetic only (Stonedoorway policy)
3. Spoken phonemes (vaikharī) for 5–10 rows — Mātṛkā order or Mālinī order
4. Visualize: form + color + body locus (tantrica2 map)
5. Drop to mental (madhyamā) — no lips
6. Pause at heart-green (dentals) longer
7. Optional: one VB or Śivasūtra line
8. Silence — let paśyantī/parā “complete itself”
9. Morning: one line log + 1 recall check (no phone first)
```

**Frequency policy:**
- Use **bed** for state (alpha/theta *as mix settings*, not medical claims)  
- Use **your voice** for phonemes — that’s the tradition’s uccāra  
- If you want “per-phoneme Hz,” treat it as **personal mnemonic experiment**, clearly labeled — not as Tantrāloka doctrine
