## The product idea

StoneDoorway is not only binaural beats or a guided journey app.

It becomes an **OS for imagination**:

```text
BOOT
  enter the Stone Doorway
  liminal space (matrix / atrium)
  you are in a threshold, not a lesson yet

RECALL BOOT
  "What are these nine worlds?"
  you must name/recall them
  → naming **activates** the worlds
  (the first task is itself a memory/install drill)

LOBBY
  grid of 9 worlds (doors / pillars / stations)
  each world = a lab runtime + an imaginal room

INHABIT
  enter a world
  faculty drill · mātṛkā · Laya · Pāṇini · text-world
  familiar/talisman appears as guide-companion

RETURN
  threshold again
  log what stuck
```

**Key mechanic:** the boot sequence is not cutscene fluff.  
Recalling the nine worlds **is** the install — Bruno method of places + Castle figure-hubs + modern spaced retrieval.

## Activation protocol (the OS boot)

```text
1. ENTER     voice: "You are now entering the Stone Doorway."
2. THRESHOLD settle breath · optional binaural bed (quiet)
3. RECALL    "Name the nine worlds."  (you answer aloud)
4. ACTIVATE  each name lights a pillar
5. GUIDE     familiar/talisman appears at the threshold
6. CHOOSE    one world · one faculty · one series
7. WORK      install · contractio · Laya · Pāṇini · speak
8. RETURN    "Bring me back."  log one line
```

**If you cannot name them all:** that is data. The grid is weaker. Re-walk the lobby.
