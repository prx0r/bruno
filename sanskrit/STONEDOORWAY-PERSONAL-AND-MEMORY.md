## Memory world — staged tests (idea)

Unlock **grid size** by passing recall tests.

| Stage | Test | Unlocks |
|-------|------|---------|
| **M1** | Name 1 world + its first object | 1-window lobby |
| **M2** | Name 2 series + 5 letters each | 2-window |
| **M3** | Name 4 worlds + bed cues | 2×2 |
| **M4** | Reconstruct 9 worlds + one rule each | 3×3 lobby |
| **M5** | Free walk: choose any door, complete work, return cleanly | OS fluency |

**Test format (audial):**

```text
AI: "Upper-left window — what is it?"
You: "Mātṛkā."
AI: "What do you hear first?"
You: "ka…"
AI: "Pass. Upper-right?"
```

Failures = data. Stay at that stage. No punishment — just re-walk.

**This is Castle faculty practice + retrieval testing + OS progression in one.**
