## What Laya Yoga actually is (Goswami)

| Term | Meaning |
|------|---------|
| **Laya** | **Absorption** (reabsorption of the emitted into its source) — *not* destruction |
| **Kuṇḍalinī** | Mind-transcendent power that absorbs grosser energies — *not* vagus nerve / bioelectricity |
| **Bindu** | Point of concentration — atom = bindu of matter; samādhi = bindu of mind |
| **Three chakra systems** | Waidika · Pouranika · Tantrika — **no single canonical chart** |
| **Mantra** | “An aspect of Kuṇḍalinī in sound-form” — *Ishtadewata* (deity in form) |
| **Uncoil + recoil** | Rise/absorb → **descend and spiritualize daily life** |

**Core formula:** *laya = absorption → bindu → return as transformed everyday consciousness.*

## How it fits Mātṛkā (the missing bridge)

From volume note `36-tattvas-sanskrit-layayoga.md` + `ro-layayoga-mantra-science`:

> **Every tattva IS a phoneme. The 50 mātṛkā phonemes ARE the 36 tattvas + vowels. Chanting Mātṛkā IS traversing the tattvas in sound. Layayoga IS systematic manipulation of these phonemes in the subtle body.**

| Layer | What it is |
|-------|------------|
| **Śabdarāśi** | Undifferentiated mass of sound |
| **Mātṛkā** | “Little mothers” — phonemes as energies of consciousness (A→Kṣa) |
| **Madhyamā** | Homogeneous OṀ differentiates into **50 mātṛkā** |
| **Each phoneme** | A *bīja* — specialized power in sound-form |
| **Laya practice** | Chant + absorption + bindu + return |

So Mātṛkā isn’t only “alphabet cards”:
- **Layer 2 (embodied blocks)** = hear/produce/feel/color/locus  
- **Layer 4 (Abhinavagupta)** = phonemes as consciousness  
- **Laya Yoga** = **how you move those blocks through the subtle body and absorb them**

## Practice implication (don’t skip Laya)

You don’t need a separate “Laya course.” Fold it into Layer 2–4:

```text
1. Install row (Mātṛkā)     — form, color, emotion, locus
2. Absorb (Laya)            — chant → mental → silence, bindu on one phoneme
3. Recoil                   — speak a real Sanskrit word using that stack
4. Log                      — what dissolved; what remained as skill
```

**Night:** binaural bed optional · **voice** phonemes required · silence is the laya phase.
