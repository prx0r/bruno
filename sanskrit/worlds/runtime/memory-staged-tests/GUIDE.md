# GUIDE — Memory world (staged tests)

> StoneDoorway. Memory world. Staged tests. You unlock the grid by remembering it.

## Loop
1. AI names the stage and the prompt type
2. You answer aloud
3. Pass → next window/test · miss → stay · re-walk

## Stages
| Stage | Ask |
|-------|-----|
| M1 | Name 1 world + first object |
| M2 | Name 2 series + 5 letters each |
| M3 | Name 4 worlds + bed cues |
| M4 | Reconstruct 9 worlds + one rule each |
| M5 | Free walk any door · work · return |

## Voice
> Listen to the prompt. Answer aloud. No peeking.
> Pass to advance. Stay if you miss. That is training.
> Log which stage you held.

## Recall prompts
- What is behind this door?
- What do you hear there?
- What is the first object?
- What is the governing rule there?
