## Three Bruno primitives

| Primitive | Meaning | Sanskrit-lab use |
|-----------|---------|------------------|
| **LOCUS** | Where something lives internally | Letter/series/passage sits in a definite place |
| **IMAGO** | Sensory/active form that represents it | Articulation + sound + colour + body + emotion as one object |
| **VINCULUM** | What binds it to the rest of cognition | Affects, place, voice, grammar, desire — dense cross-links |

### Install formula (Bruno method)

```text
hear varṇa (sound)
  → see form (devanagari + colour)
  → place in locus (Caelum region / seal)
  → give image action or emotion (vinculum)
  → relate spatially to neighbors
  → traverse until associations are automatic
```

### Contractio

**Narrow attention completely onto one internally generated object** until auditory, visual, spatial and affective qualities fuse into one stable representation.

This is the absorption technique that pairs with Laya Yoga (bindu) — Bruno *method*, Trika *content*.

```text
Chant one phoneme
  → articulation + resonance + colour + locus + emotion
  → contractio (gather all into one image)
  → silence / laya
```

### Vinculum as pedagogy

> If an idea is to become deeply installed, bind it to sensation, imagery, emotion, action, place, sound and desire — not proposition alone.

This is the **felt-Sanskrit** thesis in Bruno language.

## Caelum — spatial substrate (not “astrology palace”)

Bruno’s Seal II (*Caelum*) = **general-purpose 3D spatial indexing**.

Operational geometry (prefer this over the ambiguous woodcut):

```text
sphere
  → 2 perpendicular great circles → 4 major regions
  → 3rd orthogonal great circle → 8 octants
  → each octant: apex/base · left/right · above/below · sides
  → each distinction = addressable LOCUS
  → recursive subdivision for more capacity
```

**Principle:** *distinction produces addressability.*  
You don’t pre-count 1,440 slots — you **subdivide when needed**.

| Implementation choice | Value |
|----------------------|-------|
| One giant sphere per domain | ✓ |
| Repeated sphere templates per text | ✓ |
| Math basis | sphere ∩ 3 mutually perpendicular great circles = 8 spherical octants |
| Decorative woodcut | lower priority than operational description |

**Text-world use:** Śivasūtras (or any text) gets a Caelum substrate. Major conceptual territories occupy regions; learning subdivides regions; you always know roughly **where you are** in the knowledge.
