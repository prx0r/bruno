## The four Brunos

1. **Mnemonist** — artificial systems for storing/generating thought  
2. **Lullist** — combinatorial wheels (person → action → attribute → circumstance)  
3. **Metaphysician** — infinite living unity; multiplicity from deeper principles  
4. **Magician** — imagination, signs, *spiritus* as mediators  

They are one project. Memory art makes more sense once you know the metaphysics.

## Key ideas

### External knowledge as an internal symbolic machine
Not just remembered — **operated**. Diagrams/wheels/spatial structures = cognition organized through structured internal representations.

### Bruno wheels for language
- Ring 1: root / letter  
- Ring 2: person / agent  
- Ring 3: tense/aspect/mood  
- Ring 4: voice (Sanskrit: parasmaipada / ātmanepada)  
- Ring 5: context  

**Root × person × tense × voice → produce form.**  
Hindi: person × verb × aspect × auxiliary × object × postposition.

### Different geometries for different knowledge
| Structure | Geometry |
|-----------|----------|
| Sequence | Chain |
| Taxonomy | Tree |
| Combination | Wheel |
| Experience | Palace |
| Territory | Field |

### Knowledge by internal isomorphism
A Brunian palace’s **architecture should imitate the architecture of its subject**. Sanskrit system should behave like Sanskrit.

### De vinculis — bind, don’t merely encode
Memory binds through emotion, novelty, vividness, desire, narrative, location, repetition.  
`दरवाज़ा` = *your* door — open, slam, yell through it.

### Dreams (modern extension, not historical doctrine)
```text
DAY controlled imagination → STRUCTURE
NIGHT uncontrolled recombination → DREAM
MORNING selection → STRUCTURE UPDATED
```
Bruno + Synesius via Ficino: *phantasia* as intermediate faculty. **Not** a claim he taught lucid-dream palaces.

### Ars Notoria × Bruno
| Notoria | Bruno |
|---------|-------|
| Perfect the faculty | Engineer what the faculty operates on |
| Generals + notae | Combinatorial representation + isomorphic architecture |

Historically Bruno ≠ Notoria practitioner in any simple sense (*De magia* mentions *Ars notoria* in his classification). **Experimentally** the combination is coherent.
